# Инструкция для русского интерфейса Discord

> Сайт для разработчиков Discord (Developer Portal) есть только на английском. Ниже рядом с каждой английской кнопкой дан перевод. Сам Discord (приложение и браузер) — на русском.

## Шаг 1. Создать бота (Developer Portal, один раз)

1. Откройте https://discord.com/developers/applications и войдите своим аккаунтом Discord.
2. Справа вверху **New Application** («Новое приложение») → введите имя бота → поставьте галочку согласия → **Create** («Создать»).
3. Слева **Bot** («Бот»):
   - **Reset Token** («Сбросить токен») → **Yes, do it!** → **Copy** («Копировать»). Это токен: вставьте его в файл `.env` и никому не показывайте;
   - **Privileged Gateway Intents** включать **не нужно**.
4. Слева **Installation** («Установка»):
   - **Install Link** («Ссылка для установки») → **Discord Provided Link**;
   - в блоке **Default Install Settings → Guild Install** («Установка на сервер»):
     - **Scopes**: `bot` и `applications.commands`;
     - **Permissions** («Права»): `View Channels` (Просматривать каналы), `Send Messages` (Отправлять сообщения), `Embed Links` (Встраивать ссылки);
   - **Save Changes** («Сохранить изменения»).
5. Аватар и описание бота можно задать в **General Information** («Общая информация»).

## Шаг 2. Запустить бота

В папке `news-bot` создайте файл `.env`:

```
DISCORD_TOKEN=ваш_токен
DEFAULT_TIME=09:00
```

Windows: откройте папку `news-bot` в Проводнике, в адресной строке наберите `cmd` и нажмите Enter. Откроется командная строка, в ней выполните:

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

В окне появится строка `Ссылка-приглашение: https://discord.com/oauth2/authorize?...` — скопируйте её. Не закрывайте окно: пока оно открыто, бот работает.

## Шаг 3. Добавить бота на сервер

1. Откройте ссылку-приглашение в браузере.
2. **Добавить на сервер** → выберите сервер из списка → **Продолжить**.
   Сервера нет в списке — значит, у вас нет на нём права «Управлять сервером».
3. Проверьте галочки прав → **Авторизовать** → пройдите проверку «Я человек».
4. Бот появится в списке участников и напишет приветствие.

## Шаг 4. Настроить сводки

В любом канале сервера наберите `/` и выберите команду бота из списка:

1. `/setup channel` → в поле **сводка** выберите «📰 Новости», в поле **канал** — канал → Enter.
2. То же для «🎖️ СВО» и «📜 История России».
3. `/setup time` → в поле **время** введите, например, `09:00` (по Москве).
4. `/post_now` → все сводки появятся сразу.
5. `/setup status` — проверить, что куда настроено.

Ответы бота на эти команды видите только вы («Только вы видите это сообщение»).

## Если бот пишет «нет прав в канале»

1. Наведите на канал → шестерёнка **«Изменить канал»**.
2. **Права доступа** → **«+»** рядом с «Роли/участники» (или **«Добавить участников или роли»**) → найдите бота.
3. Поставьте зелёные галочки ✅: **Просматривать каналы**, **Отправлять сообщения**, **Встраивать ссылки** → **Сохранить изменения**.
4. Повторите `/setup channel`.

## Кто может пользоваться командами

По умолчанию команды `/setup` и `/post_now` видят только участники с правом «Управлять сервером». Изменить это можно так: **Настройки сервера** (имя сервера сверху слева → «Настройки сервера») → **Интеграции** → ваш бот → **Управлять** → выберите роли/каналы для каждой команды.

## Убрать бота с сервера

**Настройки сервера → Интеграции →** бот **→ Управлять → Выгнать**. Или: ПКМ по боту в списке участников → **Выгнать**.

## Работа 24/7

Пока бот запущен на домашнем компьютере, он работает только когда компьютер включён. Для круглосуточной работы — VPS с Linux, см. раздел 4 в [README.md](README.md).
